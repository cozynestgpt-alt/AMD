【전년대비 보고서 추가】

생성 파일:
  output/YYYY-MM/판매수수료_전년대비보고서.xlsx
  output/판매수수료_전년대비보고서.xlsx

실행 방법:
  1) 전체 실행: 실행.bat 또는 run.py 실행 시 월별손익DB 업데이트 후 자동 생성
  2) 보고서만 생성: 전년대비보고서만생성.bat 실행

입력 기준:
  - DB/월별손익DB.xlsx: 표1 및 손익 지표 기준
  - input/매장구분_행사_신규_폐점_YYYYMM.xlsx: 동일/신규/폐점/행사 구분 기준

생성 시트:
  Dashboard, 표1, 구분, 피벗값_구분, 피벗값_매장명(동일),
  피벗값_매장명(동일) 값_영업이익순, 피벗값_매장명 (폐점),
  피벗값_매장명 (행사), 피벗값_매장명 (신규)

주의:
  판매수수료작업시트_AMD.xlsx는 수수료·공제 중심 자료입니다.
  전년대비 보고서의 생산원가, 영업이익, 총경비, 순이익은 월별손익DB 기준입니다.
