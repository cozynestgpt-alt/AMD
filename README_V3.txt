==========================================
  판매수수료 자동계산 시스템 V4
==========================================

【핵심 변경】
1. 월별입력_템플릿.xlsx 및 input/월별입력_YYYY-MM.xlsx 완전 폐지
2. 2026년 5월까지 DB는 DB/월별손익DB.xlsx에 값만 이관
3. 원본 DB의 외부링크/PowerQuery/수식 참조를 제거한 깨끗한 신규 DB 사용
4. 2026년 6월부터 매월 output/YYYY-MM/매출집계_분석.xlsx 자료로 DB 자동 업데이트
5. 기준일, 분기, 반기, 시즌 분석 필드 자동 생성

【기준일】
- 기준일은 해당월 말일입니다.
  예: 2026-06 → 2026-06-30

【분기】
- 1Q: 1~3월
- 2Q: 4~6월
- 3Q: 7~9월
- 4Q: 10~12월

【시즌】
- SS: 3월~8월
- FW: 9월~다음해 2월
- 1~2월은 전년도 FW로 구분합니다.
  예: 2026-01, 2026-02 → 2025FW

【주요 파일】
- run.py: 기존 정산 + DB 업데이트 + 보고서 생성 통합 실행
- history_update.py: 매출집계_분석.xlsx → 월별손익DB.xlsx 업데이트
- history_report.py: 연도별/분기별/시즌별 손익분석 보고서 생성
- DB/월별손익DB.xlsx: 정식 월별 손익 DB
- output/연도별_분기별_시즌별_손익분석.xlsx: 경영진 보고용 분석 파일

【매월 실행 순서】
1. input 폴더에 해당월 자료를 넣습니다.
2. 실행.bat 또는 실행_v3.bat를 실행합니다.
3. 정산월을 입력합니다. 예: 2026-06 또는 202606
4. 기존 output 파일 생성 후, 월별손익DB가 자동 업데이트됩니다.
5. output/연도별_분기별_시즌별_손익분석.xlsx가 자동 생성됩니다.

【DB 업데이트만 실행】
- 이미 output/YYYY-MM/매출집계_분석.xlsx가 생성되어 있다면 DB업데이트만.bat를 실행해도 됩니다.

【보고서만 재생성】
- DB 내용은 그대로 두고 보고서만 다시 만들려면 보고서만생성.bat를 실행합니다.

【주의】
- 2026년 5월까지는 기존 DB_202605까지.xlsx의 수치를 보존합니다.
- 2026년 6월부터 같은 년-월 + 매장코드가 DB에 있으면 기존 행을 삭제하고 새 행으로 교체합니다.
- DB 파일은 외부 링크가 없는 값 기반 파일입니다.
- templates 폴더에는 기존 salary_system에서 사용하던 템플릿 파일을 복사해 넣어야 합니다.
