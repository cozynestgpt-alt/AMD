============================================================
판매수수료 자동계산 및 경영보고서 생성 시스템 V7 최종 운영안
============================================================

[핵심 운영 원칙]
1. 실행_v7.bat 또는 실행.bat 더블클릭만으로 전체 작업을 실행합니다.
2. 2026년 5월까지의 월별손익DB 값은 기존 DB 기준값을 보존합니다.
3. 2026년 6월부터는 output/YYYY-MM/매출집계_분석.xlsx를 기준으로 월별손익DB를 업데이트합니다.
4. 수금율은 V+ 기준, 원가배수/경비율/영업이익률/순이익율은 매출 V- 기준으로 계산합니다.
   - 매출 V- = 매출금액(V+) / 1.1
5. input/매장구분_행사_신규_폐점_YYYYMM.xlsx가 있으면 행사/신규/폐점/동일 분류는 이 파일을 우선 적용합니다.
6. 기준일은 해당월 말일입니다.
7. 분기와 시즌을 자동 구분합니다.
   - 분기: 1Q, 2Q, 3Q, 4Q
   - 시즌: SS = 3월~8월, FW = 9월~다음해 2월
   - 1~2월은 전년도 FW 시즌으로 관리합니다.

[실행 파일]
- 실행_v7.bat: 전체 정산 및 모든 보고서 생성
- 실행.bat: 실행_v7.bat와 동일한 최종 실행 파일
- DB업데이트_보고서만.bat: 정산 파일 생성 없이 DB 업데이트/보고서 재생성
- 경영보고서만생성_v7.bat: DB 기준 보고서만 재생성

[전체 실행 흐름]
1. run.py 실행
2. 판매수수료 계산
3. 아르바이트_정산서.xlsx 생성
4. 매출집계.xlsx 생성
5. 경비지원및공제_집계.xlsx 생성
6. 매출집계_분석.xlsx 생성
7. 판매수수료작업시트_AMD.xlsx 생성
8. 개별통지문.xlsx 생성
9. 판매수수료집계.xlsx 생성
10. 중간관리판매수수료이체내역.xlsx 생성
11. 세금계산서_YYYY-MM.xlsx 생성
12. 처리결과_요약.txt 생성
13. 월별손익DB 업데이트(2026-06부터)
14. 연도별_분기별_시즌별_손익분석.xlsx 생성
15. 경영분석보고서.xlsx 생성
16. 판매수수료_전년대비보고서.xlsx 생성

[주요 출력 파일]
- output/YYYY-MM/매출집계_분석.xlsx
- output/YYYY-MM/판매수수료_전년대비보고서.xlsx
- output/연도별_분기별_시즌별_손익분석.xlsx
- output/경영분석보고서.xlsx
- DB/월별손익DB.xlsx

[필수 템플릿]
templates 폴더에는 아래 3개 파일이 필요합니다.
1. 개별통지문_템플릿.xlsx
2. 판매수수료집계_템플릿.xlsx
3. 세금계산서출력_템플릿.xlsx

[미사용 템플릿]
- 월별입력_템플릿.xlsx: 사용하지 않음
- 중간관리판매수수료이체내역_템플릿.xlsx: 현재 transfer_report.py가 직접 생성하므로 사용하지 않음

[매월 input 폴더 권장 파일]
- 사원마스터.xlsx
- 영*판매*YYYYMM*.xlsx
- ◈매장공제건 집계*.xlsx
- ★*경비내역서*.xlsx
- *재고실사*공제건*합계*.xlsx
- 사원현황_일용직_YYYYMM.xlsx
- 급여상여명세서_일용직_YYYYMM.xlsx
- 급여상여명세서_매장직_YYYYMM.xlsx
- 월별근태_일용직_YYYYMM.xlsx
- *로젠*고객직배*.xlsx
- 매장전화요금내역.xlsx
- 중간관리매장_매입세금계산서_기재사항정보.xlsx
- 매장구분_행사_신규_폐점_YYYYMM.xlsx (권장)

[주의]
- 2026-05 이하 월을 실행해도 월별손익DB는 기본적으로 업데이트하지 않고 기존 DB를 보존합니다.
- 기존 월을 강제로 재작성해야 할 때는 history_update.update_history(..., force=True)를 개발자가 직접 사용해야 합니다.
- 매월 신규/행사/폐점 분류가 바뀌면 input/매장구분_행사_신규_폐점_YYYYMM.xlsx를 반드시 최신화하세요.
