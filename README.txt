==========================================
  판매수수료 자동계산 시스템 V4 Final
==========================================

【V4 정리 내용】
1. templates 사용 현황 전수 점검
2. 중간관리판매수수료이체내역_템플릿.xlsx 미사용 확인
3. 월별입력_템플릿.xlsx 및 input/월별입력_YYYY-MM.xlsx 미사용 유지
4. 필수 템플릿 목록을 3개로 정리
5. 입력 파일/출력 파일/모듈 의존성/삭제 가능 파일 문서화
6. audit_system.py 추가
7. V3의 기준일·분기·시즌 분석 구조 유지

【기준일】
- 기준일은 해당월 말일입니다.
  예: 2026-06 → 2026-06-30

【분기】
- 1Q: 1~3월
- 2Q: 4~6월
- 3Q: 7~9월
- 4Q: 10~12월

【시즌】
- SS: 3월~8월
- FW: 9월~다음해 2월
- 1~2월은 전년도 FW로 구분합니다.
  예: 2026-01, 2026-02 → 2025FW

【필수 템플릿】
기존 salary_system/templates 폴더에서 아래 3개만 복사하면 됩니다.

1. 개별통지문_템플릿.xlsx
2. 판매수수료집계_템플릿.xlsx
3. 세금계산서출력_템플릿.xlsx

【필수에서 제외된 템플릿】
- 중간관리판매수수료이체내역_템플릿.xlsx
  → transfer_report.py가 템플릿 없이 직접 생성합니다.

- 월별입력_템플릿.xlsx
  → V4에서 월별입력 구조를 사용하지 않습니다.

- 사원마스터_템플릿.xlsx
  → 참고용 양식일 뿐 실행 코드에서 읽지 않습니다.

- 매출_템플릿.xlsx
  → 참고용 양식일 뿐 실행 코드에서 읽지 않습니다.

【주요 실행 파일】
- 실행.bat: 기본 실행
- 실행_v3.bat: V3/V4 통합 실행용으로 유지
- DB업데이트만.bat: 이미 생성된 매출집계_분석.xlsx만 DB에 반영
- 보고서만생성.bat: DB 기준 보고서만 재생성

【주요 Python 파일】
- run.py: 기존 정산 + DB 업데이트 + 보고서 생성 통합 실행
- history_update.py: 매출집계_분석.xlsx → 월별손익DB.xlsx 업데이트
- history_report.py: 연도별/분기별/시즌별 손익분석 보고서 생성
- audit_system.py: 템플릿 참조와 외부 링크 검사

【주요 DB/보고서】
- DB/월별손익DB.xlsx
- output/연도별_분기별_시즌별_손익분석.xlsx

【문서】
docs 폴더에 아래 점검 문서를 포함했습니다.

1. 01_템플릿_사용현황.txt
2. 02_입력파일_사용현황.txt
3. 03_출력파일_생성흐름.txt
4. 04_모듈_의존성.txt
5. 05_삭제가능_파일목록.txt
6. 06_필수파일목록.txt

【매월 실행 순서】
1. input 폴더에 해당월 자료를 넣습니다.
2. templates 폴더에 필수 템플릿 3개가 있는지 확인합니다.
3. 실행.bat를 실행합니다.
4. 정산월을 입력합니다. 예: 2026-06 또는 202606
5. output/YYYY-MM/ 폴더에 월별 정산 파일이 생성됩니다.
6. DB/월별손익DB.xlsx가 자동 업데이트됩니다.
7. output/연도별_분기별_시즌별_손익분석.xlsx가 자동 생성됩니다.

【주의】
- 같은 년-월 + 매장코드가 DB에 있으면 기존 행을 삭제하고 새 행으로 교체합니다.
- DB 파일은 값 기반 파일이며 외부 링크가 없도록 재생성했습니다.
- 필수 템플릿 3개가 없으면 해당 출력물 생성이 실패할 수 있습니다.
