판매수수료 자동계산 및 경영분석 시스템 V8 Final Release
======================================================

1. 목적
- 판매수수료 월별 정산 자동화
- 월별손익DB 자동 관리
- 연도별/분기별/시즌별 손익분석 자동 생성
- 경영분석보고서 자동 생성
- 판매수수료 전년대비보고서 자동 생성

2. 기본 실행 파일
- 실행.bat: 월별 정산부터 DB 업데이트, 전체 보고서 생성까지 수행하는 메인 실행 파일
- 보고서만생성.bat: DB 기준으로 보고서 3종을 재생성
- DB업데이트만.bat: 이미 생성된 매출집계_분석.xlsx를 월별손익DB에 반영
- 전년대비보고서만생성.bat: 전년대비보고서만 별도로 재생성

3. 매월 운영 순서
1) input 폴더에 해당 월 자료를 넣습니다.
2) templates 폴더에 필수 템플릿이 있는지 확인합니다.
3) 실행.bat를 더블클릭합니다.
4) 정산월을 입력합니다. 예: 2026-06 또는 202606
5) output 폴더의 결과물을 확인합니다.

4. 보고서만 재생성
보고서 서식이나 분류 기준 파일을 수정한 뒤에는 보고서만생성.bat를 실행합니다.
이 파일은 아래 3개 보고서를 순서대로 생성합니다.
- output/연도별_분기별_시즌별_손익분석.xlsx
- output/경영분석보고서.xlsx
- output/판매수수료_전년대비보고서.xlsx

5. DB 기준
- 2026년 5월까지는 기존 DB 기준값을 보존합니다.
- 2026년 6월부터는 output/YYYY-MM/매출집계_분석.xlsx 기준으로 DB를 업데이트합니다.
- 업데이트 기준 키는 년월 + 매장코드입니다.

6. KPI 계산 기준
- 매출금액: V+ 기준
- 수금액: V+ 기준
- 생산원가, 총경비, 영업이익, 순이익: V- 기준
- 수금율 = 수금액(V+) / 매출금액(V+)
- 원가배수 = (매출금액(V+) / 1.1) / 생산원가(V-)
- 경비율 = 총경비(V-) / (매출금액(V+) / 1.1)
- 영업이익률 = 영업이익(V-) / (매출금액(V+) / 1.1)
- 순이익률 = 순이익(V-) / (매출금액(V+) / 1.1)

7. 시즌 기준
- SS: 3월부터 8월까지
- FW: 9월부터 다음해 2월까지
- 1월과 2월은 전년도 FW로 구분합니다.

8. 매장구분 파일
파일명 예시:
input/매장구분_행사_신규_폐점_202605.xlsx

구분값:
- 동일
- 신규
- 폐점
- 행사

이 파일은 행사매장분석, 신규매장분석, 폐점매장분석, 동일매장분석, 전년동기대비 분석에 우선 적용됩니다.
