템플릿 사용 현황 - salary_system V4
====================================

[필수 템플릿]

1. templates/개별통지문_템플릿.xlsx
   - 사용 위치: run.py / make_notice()
   - 코드 근거: BASE / "templates" / "개별통지문_템플릿.xlsx"
   - 생성 파일: output/YYYY-MM/개별통지문.xlsx
   - 없을 경우: 개별통지문 생성 실패

2. templates/판매수수료집계_템플릿.xlsx
   - 사용 위치: sales_summary.py / make_sales_summary()
   - 코드 근거: base_dir / "templates" / "판매수수료집계_템플릿.xlsx"
   - 생성 파일: output/YYYY-MM/판매수수료집계.xlsx
   - 없을 경우: 판매수수료집계 생성 실패

3. templates/세금계산서출력_템플릿.xlsx
   - 사용 위치: tax_invoice_report.py / make_tax_invoice()
   - 코드 근거: templates/세금계산서출력_템플릿.xlsx
   - 생성 파일: output/YYYY-MM/세금계산서_YYYY-MM.xlsx
   - 없을 경우: 세금계산서 생성 실패

[현재 코드 기준 불필요 템플릿]

1. templates/중간관리판매수수료이체내역_템플릿.xlsx
   - 사용 안 함.
   - transfer_report.py는 템플릿을 읽지 않고 openpyxl.Workbook()으로 이체내역서를 직접 생성합니다.
   - 따라서 V4 기준 필수 템플릿 목록에서 제외했습니다.

2. templates/월별입력_템플릿.xlsx
   - V3/V4에서 월별입력 구조는 완전히 폐지되었습니다.
   - input/월별입력_YYYY-MM.xlsx도 사용하지 않습니다.

3. templates/사원마스터_템플릿.xlsx
   - 실행 시 input/사원마스터.xlsx는 사용하지만 템플릿 파일 자체는 읽지 않습니다.
   - 신규 사원마스터 양식 참고용으로 보관할 수는 있으나 실행 필수 파일은 아닙니다.

4. templates/매출_템플릿.xlsx
   - 실행 시 영*판매*.xlsx 입력 파일은 사용하지만 매출 템플릿 파일 자체는 읽지 않습니다.
   - 참고용으로 보관 가능하나 실행 필수 파일은 아닙니다.

[정리 결론]
- V4 필수 템플릿은 3개입니다.
  1) 개별통지문_템플릿.xlsx
  2) 판매수수료집계_템플릿.xlsx
  3) 세금계산서출력_템플릿.xlsx

- 중간관리판매수수료이체내역_템플릿.xlsx는 현재 코드에서는 없어도 됩니다.
