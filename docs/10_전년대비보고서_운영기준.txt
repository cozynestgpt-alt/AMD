전년대비 보고서 운영 기준
========================

1. 생성 파일
- output/YYYY-MM/판매수수료_전년대비보고서.xlsx
- output/판매수수료_전년대비보고서.xlsx

2. 사용 데이터
- 표1: DB/월별손익DB.xlsx 의 년도별월별DB 시트 기준
- 구분: input/매장구분_행사_신규_폐점_YYYYMM.xlsx 기준 우선 적용
- 구분 파일이 없거나 누락된 매장은 DB 기준으로 신규/폐점/동일을 보조 판정

3. 분류 기준
- 동일: 전년과 당년에 모두 비교 가능한 정상 비교 매장
- 신규: 당년에 새로 반영되는 매장
- 폐점: 전년 실적은 있으나 당년 비교에서 제외/폐점으로 관리할 매장
- 행사: 행사성 매장으로 별도 분석하는 매장

4. 생성 시트
- Dashboard
- 표1
- 구분
- 피벗값_구분
- 피벗값_매장명(동일)
- 피벗값_매장명(동일) 값_영업이익순
- 피벗값_매장명 (폐점)
- 피벗값_매장명 (행사)
- 피벗값_매장명 (신규)

5. 주의사항
- 판매수수료작업시트_AMD.xlsx는 수수료/공제 중심 보고서이며 생산원가, 영업이익 등 손익분석 컬럼은 DB 기준으로 관리합니다.
- 2026년 5월까지는 기존 DB 보존 대상입니다.
- 2026년 6월부터 매월 매출집계_분석.xlsx가 월별손익DB에 업데이트된 후 본 보고서가 생성됩니다.
