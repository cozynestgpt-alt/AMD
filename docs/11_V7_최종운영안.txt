V7 최종 운영안

1. 실행_v7.bat 하나로 전체 정산 및 경영보고서 생성.
2. run.py는 history_update.run()을 호출하며, history_update.py가 다음 보고서를 함께 생성함.
   - history_report.py: 연도별/분기별/시즌별 손익분석
   - management_report.py: 경영분석보고서
   - year_compare_report.py: 판매수수료 전년대비보고서
3. KPI 계산 기준
   - 수금율 = 수금액(V+) / 매출금액(V+)
   - 원가배수 = (매출금액(V+) / 1.1) / 생산원가(V-)
   - 경비율 = 총경비(V-) / (매출금액(V+) / 1.1)
   - 영업이익률 = 영업이익(V-) / (매출금액(V+) / 1.1)
   - 순이익율 = 순이익(V-) / (매출금액(V+) / 1.1)
4. DB 보호 기준
   - 2026년 5월까지: 기존 DB 기준값 보존
   - 2026년 6월부터: 매출집계_분석.xlsx 기준 업데이트
5. 매장구분 파일
   - input/매장구분_행사_신규_폐점_YYYYMM.xlsx 우선 적용
   - 구분값: 동일, 신규, 폐점, 행사
