KPI 계산 기준 변경 안내 (V6)

1. 기본 전제
- 판매금액/매출금액은 V+ 기준입니다.
- 생산원가(V-), 총경비, 영업이익(V-), 순이익은 V- 기준입니다.

2. 비율 산출 기준
서로 같은 기준으로 비교하기 위해, 생산원가/경비/이익 관련 배수와 율은 매출금액을 V-로 환산하여 계산합니다.

- 매출(V-) = 매출금액(V+) / 1.1
- 수금율 = 수금액(V+) / 매출금액(V+)
- 원가배수 = 매출금액(V+) / 1.1 / 생산원가(V-)
- 경비율 = 총경비(V-) / (매출금액(V+) / 1.1)
- 영업이익률 = 영업이익(V-) / (매출금액(V+) / 1.1)
- 순이익율 = 순이익(V-) / (매출금액(V+) / 1.1)

3. 반영 파일
- year_compare_report.py
- management_report.py
- history_update.py
- history_report.py
- sales_analysis.py

4. 주의사항
- 수금율은 수금액과 매출액이 모두 V+ 기준이므로 기존처럼 V+ 기준으로 계산합니다.
- 원가배수, 경비율, 영업이익률, 순이익율은 모두 V- 매출 기준으로 통일했습니다.
