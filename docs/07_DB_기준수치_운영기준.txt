월별손익DB 기준 수치 운영기준

1. 2026년 5월까지
- 기준 파일: 기존 DB_202605까지.xlsx
- 월별손익DB.xlsx의 2026년 5월까지 수치는 기존 DB의 값을 그대로 이관합니다.
- 매출집계_분석.xlsx로 2026년 5월 이전 월을 재업데이트하지 않습니다.

2. 2026년 6월부터
- salary_system 실행 후 생성되는 output/YYYY-MM/매출집계_분석.xlsx를 기준으로 DB를 업데이트합니다.
- 업데이트 키: 년-월 + 매장코드
- 같은 키가 있으면 기존 행을 삭제하고 새 자료로 교체합니다.

3. 기준일/분기/시즌
- 기준일: 해당월 말일
- 분기: 1Q~4Q
- 반기: 상반기/하반기
- 시즌: SS=3~8월, FW=9~다음해 2월
- 1~2월은 전년도 FW로 구분합니다. 예: 2026-01 → 2025FW

4. history_update.py 보호 로직
- 2026-05 이하 월은 기본적으로 업데이트를 건너뜁니다.
- 예외적으로 강제 업데이트가 필요한 경우에만 force=True 옵션을 사용합니다.
