삭제 가능 또는 보관용 파일 목록 - salary_system V4
===============================================

[삭제 가능 - 현재 코드에서 사용하지 않음]

1. templates/중간관리판매수수료이체내역_템플릿.xlsx
   - 사유: transfer_report.py가 직접 파일 생성

2. templates/월별입력_템플릿.xlsx
   - 사유: V4에서 월별입력 구조 폐지

3. input/월별입력_YYYY-MM.xlsx
   - 사유: V4에서 사용하지 않음

[실행에는 불필요하나 참고용 보관 가능]

1. templates/사원마스터_템플릿.xlsx
   - 사원마스터 양식 참고용
   - 실행 시 실제로 읽는 파일은 input/사원마스터.xlsx

2. templates/매출_템플릿.xlsx
   - 매출 파일 양식 참고용
   - 실행 시 실제로 읽는 파일은 input/영*판매*.xlsx

3. input/레-영-판매대행변경*.xlsx
   - 현재 V4 코드에서는 직접 읽지 않음
   - 인사 변경 검토용 참고 파일로 보관 가능

4. backup/*.xlsx
   - DB 업데이트 전 자동 백업 파일
   - 운영상 보관 권장. 오래된 백업은 별도 보관/삭제 가능.

[삭제 금지]

1. DB/월별손익DB.xlsx
   - 누적 손익 DB 원본

2. output/YYYY-MM/매출집계_분석.xlsx
   - 해당월 DB 업데이트 기준 파일

3. templates/개별통지문_템플릿.xlsx
4. templates/판매수수료집계_템플릿.xlsx
5. templates/세금계산서출력_템플릿.xlsx
