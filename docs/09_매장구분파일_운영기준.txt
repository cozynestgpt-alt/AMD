매장구분 파일 운영 기준
=========================

1. 목적
- 매월 변경되는 행사매장, 신규매장, 폐점매장을 수작업 판단 기준 그대로 보고서에 반영합니다.
- DB 수치만으로 자동판단하면 행사/신규/폐점 구분이 애매할 수 있으므로, input 폴더의 매장구분 파일을 최우선 기준으로 사용합니다.

2. 파일명
input/매장구분_행사_신규_폐점_YYYYMM.xlsx
예) input/매장구분_행사_신규_폐점_202606.xlsx

3. 표준 구조
시트명: 구분
필수 컬럼:
- 매장코드 또는 행 레이블
- 매장명
- 구분

4. 구분값
- 동일
- 신규
- 폐점
- 행사

5. 적용 보고서
- 행사매장분석
- 신규매장분석
- 폐점매장분석
- 동일매장분석
- 전년동기대비
- Dashboard 자동 코멘트

6. 적용 우선순위
1) 해당 월 매장구분 파일
2) input 폴더의 가장 최근 매장구분 파일
3) management_report.py의 legacy 기준(EVENT_INFO, CLOSED_INFO)
4) 전년/당년 매출 존재 여부 기준 자동분류

7. 주의사항
- 2026년 5월까지의 금액은 월별손익DB.xlsx의 기존 DB 수치를 사용합니다.
- 2026년 6월 이후에도 금액은 월별손익DB.xlsx를 기준으로 하며, 매장구분 파일은 보고서 분류 기준으로만 사용합니다.
